## About

- Design and build **scalable backend services in Python**, architected around clean code principles and best practices for API development.
- Focused on **high-load** — implementing rate limiting strategies, efficient database queries, lazy loading patterns, and graceful error handling under pressure.
- Leverage **Apache Kafka** for reliable message streaming and **gRPC** for high-performance inter-service communication.
- Own the **full backend lifecycle**: database schema design with Alembic migrations, RESTful & gRPC API endpoint development, caching strategies with Redis, and secure authentication with JWT tokens.
- Deploy and manage services on **Linux** environments, ensuring optimal performance and stability.
- Treat **security as a first-class concern**, implementing both symmetric (HS256) and asymmetric (RS256) encryption for different use cases.
- Write **maintainable, testable code** with clear separation of concerns — configuration management, dependency injection, and comprehensive testing over quick hacks.

## Engineering Values

- **Performance & Scalability First** — Optimized queries, intelligent caching, rate limiting, and efficient serialization (gRPC) ensure systems handle high load gracefully. Slow responses are bugs, not features.
- **Reliability Through Events** — Apache Kafka enables decoupled, resilient systems. Data integrity and message delivery guarantees are paramount.
- **Security by Design** — Flexible JWT implementation supporting both HS256 and RS256 algorithms. Proper validation and defense-in-depth approach. Security is never an afterthought.
- **Clean, Testable Code** — Clear structure, explicit dependencies, and comprehensive tests. Code should be readable, maintainable, and predictable.
- **Simplicity Over Complexity** — Straightforward solutions win in production. Every layer of abstraction must earn its place. Linux provides the stable foundation.
